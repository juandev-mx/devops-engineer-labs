# Understanding Lifecycle Rules

Terraform provides a special block called:

```hcl
lifecycle
```

that allows engineers to control how resources behave during creation, updates, and deletion.

Example:

```hcl
lifecycle {
    prevent_destroy = true
}
```

This configuration prevents Terraform from destroying the resource even if a destroy operation is requested.

---

# Lifecycle Rule Used

## prevent_destroy

```hcl
lifecycle {
    prevent_destroy = true
}
```

### Purpose

Protect critical resources from accidental deletion.

### Common Real-World Examples

- Production databases
- Kubernetes clusters
- Load balancers
- Storage buckets
- DNS zones
- Critical virtual machines

### Benefits

- Prevents accidental data loss
- Protects production environments
- Adds an extra layer of infrastructure security
- Reduces operational risks

# Terraform State

Terraform stores information about managed resources in:

```text
terraform.tfstate
```

The state file keeps track of:

- Resource IDs
- Resource attributes
- Provider information
- Infrastructure metadata

Example tracked values:

```text
Resource Type: random_pet
Resource Name: super_pet
Prefix: Mr
Length: 10
```

---

# Important Note About State Files

Terraform state files should generally not be committed to public repositories.

Recommended practice:

```gitignore
*.tfstate
*.tfstate.backup
.terraform/
```

State files may contain:

- Infrastructure metadata
- Sensitive information
- Resource identifiers
- Cloud configuration details


Terraform will block the operation because:

```hcl

```

# Expected Error

When attempting to destroy the resource, Terraform returns an error similar to:

```text
Error: Instance cannot be destroyed

Resource random_pet.super_pet has lifecycle.prevent_destroy set.
```

This confirms the protection mechanism is working correctly.

# Key Concepts Learned

## Lifecycle Meta-Arguments

Terraform supports several lifecycle controls:

```hcl
create_before_destroy
```

Create replacement resources before removing existing ones.

```hcl
prevent_destroy
```

Block resource destruction.

```hcl
ignore_changes
```

Ignore modifications to selected attributes.
