# DevOps Engineer Labs

Welcome to my DevOps Engineer Labs repository.

This repository showcases the hands-on projects, labs, and practical exercises I completed as part of the KodeKloud DevOps Engineer Learning Path. The collection covers key DevOps and Cloud technologies including Linux, Shell Scripting, Docker, Kubernetes, Helm, Jenkins, Terraform, Prometheus, ArgoCD, and Infrastructure Automation.

Each folder contains documented implementations, configuration files, deployment manifests, command outputs, and supporting evidence that demonstrate practical experience with real-world DevOps workflows and cloud-native technologies.

The goal of this repository is to continuously build and document production-focused skills in automation, containerization, orchestration, monitoring, CI/CD, GitOps, and infrastructure management.
